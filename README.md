# Inteligência Artificial Aplicada à Redação Científica e Análise de Experimentos

Curso voltado para estudantes de Física, Engenharia e áreas correlatas, com foco na aplicação prática de Inteligência Artificial, Python e Google Colab na análise de dados experimentais e produção científica.

---

# Objetivos

- Introduzir ferramentas de IA aplicadas à ciência
- Desenvolver habilidades em Python e Google Colab
- Aplicar regressão, análise de erros e visualização de dados experimentais
- Discutir ética científica e uso responsável de IA
- Produzir notebooks científicos reproduzíveis

---
